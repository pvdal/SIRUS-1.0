/**
 * Informações sobre o PHP
 */

O que é PHP-FPM?
- PHP-FPM (FastCGI Process Manager) é uma forma do PHP rodar junto a servidores web, como Nginx ou Apache.
- Ele gerencia processos PHP, permitindo que várias requisições HTTP sejam processadas simultaneamente,
  de forma mais eficiente do que o PHP “padrão” rodando via CGI.
O que é um pool?
- Um pool é um conjunto de processos PHP-FPM que serve requisições para um site ou aplicação específica.
- É possível ter vários pools, por exemplo:
    - Um pool para localhost (desenvolvimento)
    - Outro para meusite.com (produção)
- Cada pool pode ter configurações diferentes: número de processos, usuário, limites de memória, etc.

# Configuração para php.ini:
-> /etc/php/8.3/fpm/           ; configurações de PHP para requisições via web.
-> /etc/php/8.3/cli/           ; usado para rodar PHP diretamente no terminal.

upload_max_filesize = 5M       ; tamanho máximo de cada arquivo
post_max_size = 80M            ; deve ser maior que a soma dos arquivos + overhead da requisição
memory_limit = 256M            ; memória máxima por processo PHP (importante para uploads e processamento)
max_execution_time = 90        ; tempo máximo de execução do script (em segundos)
max_input_time = 120           ; tempo que o php demora para processar os dados recebidos
max_file_uploads = 12          ; número máximo de arquivos que podem ser enviados

OBS: M significa megabyte

# Configuração para www.conf:
-> /etc/php/8.3/fpm/pool.d/           ; www.conf define como os processos PHP-FPM são gerenciados (pool de execução)

pm = dynamic                          ; define que os processos serão terminados e iniciados dinamicamente
pm.max_children = 15                  ; ajustar conforme a memória disponível no servidor (cada processo pode consumir 30MB–80MB)
pm.start_servers = 5                  ; quantos processos iniciam e ficam prontos pra serem utilizados quando o FPM inicia

; mantém de 5 a 10 processos ociosos, prontos para requisições sem criar processo extras a cada acesso
pm.min_spare_servers = 5
pm.max_spare_servers = 10
pm.max_requests = 500

listen = /run/php/php8.3-fpm.sock     ; como o nginx vai se conectar ao PHP

; usuário e grupo (deve estar como no nginx)
listen.owner = www-data
listen.group = www-data

# OBS.: Os valores deste documento devem ser ajustados conforme o ambiente no qual o sistema será aplicado, considerando recursos do servidor, rede e volume de acessos esperados.
